# Театр

REST API театральной кассы. 

## Сущности и связи

`Play` — спектакль: название, длительность и возрастное ограничение.
`TheatreHall` — зал с уникальным названием и количеством мест.
`Performance` — показ спектакля в зале в заданное время, с базовой ценой и статусом.
`User` — покупатель с уникальным email.
`Ticket` — место пользователя на представлении, со статусом и сохранённой ценой покупки/возврата.

представление ссылается на спектакль и зал, билет на представление и пользователя, на одно место представления может существовать только одна активная резервация или покупка, отменённый или возвращённый билет сохраняется в истории, но место можно занять повторно

длительность,цена и вместимость должны быть положительными


## REST API

Каждая сущность доступна по `/api/plays`, `/api/theatre-halls`, `/api/performances`, `/api/users` и `/api/tickets`: список и получение по ID (`GET`), создание (`POST`), частичное изменение (`PATCH`) и удаление (`DELETE`).

Бизнес-операции (`/api/operations`):

1. `POST /tickets/{id}/purchase` — покупает только зарезервированный билет на предстоящее запланированное представление и фиксирует текущую цену.
2. `POST /tickets/{id}/cancel-reservation` — отменяет только резервацию до начала представления.
3. `POST /tickets/{id}/refund` — фиксирует возврат купленного билета до начала представления; статус становится `REFUNDED`, цена покупки сохраняется.
4. `POST /performances/{id}/cancel` — отменяет предстоящее запланированное представление: резервации становятся `CANCELLED`, купленные билеты — `REFUNDED`.
5. `PATCH /performances/{id}/reschedule` — переносит представление на будущее время, только если новый интервал свободен в том же зале.

Билеты создаются только в статусе `RESERVED`; менять статусы через CRUD нельзя. Новые представления должны быть будущими, а занятые интервалы одного зала не могут пересекаться. Изменения бизнес-операций выполняются транзакционно. Ошибки ввода возвращаются как `400`, отсутствующие записи — `404`, недопустимое состояние или занятое место/время — `409`.
